Seed Sample Courses

Dev-only helper: creates sample courses with real lessons in Firestore, so courses.html, lesson.html, and progress tracking all have something real to work with. You must be logged in (any account) for this to work, since course creation requires instructorId == request.auth.uid. This is safe to run more than once — it always adds new course docs (it doesn't check for duplicates), so only run it once or twice. Delete this file once you have real courses from real instructors.
